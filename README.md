# Güvercin Meclisi Kararname Üreticisi

Bu yazılım, İstanbul'un çeşitli meydanlarında *fiilen* toplanan **Yüksek Güvercin Meclisi**'nin resmi kararlarını üretmek üzere geliştirilmiştir.

## Yasal dayanak

- 1923 tarihli hayali *Semavi Canlılar İdare Nizamnamesi*
- Eminönü 3. Köprü altı olağanüstü oturum tutanakları
- Bir kedi tarafından onaylanmamış ama itiraz da edilmemiş protokol

## Kurulum

```bash
python3 kararname.py
```

Bağımlılık yoktur. Sadece Python 3. Güvercin de gerekmez; yazılım onların yerine düşünür.

## Kullanım

Program her çalıştırıldığında:

1. Meclisi açar
2. Rastgele madde sayısı belirler
3. Trafik, ekmek, balkon ve rüzgar konularında kararname basar
4. Mühür basar

## Bilimsel iddia

Bu proje, şehir planlamasının aslında güvercinlerin kolektif iradesiyle yönetildiğini *ispatlamaz*. Sadece iddia eder. İddia yeter.

## Sık sorulan sorular

Evet. Kararname üretir. Uygulanıp uygulanmaması belediyenin ve kedilerin insafınadır.

**Neden Türkçe?**  
Çünkü Eminönü'ndeki güvercinler bu dile alışkın.

**Siyasi midir?**  
Hayır. Kesinlikle hayır. Baksana ne kadar resmi.
